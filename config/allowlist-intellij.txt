# Every entry is a name-matching false positive: the deprecated symbol's member name collides
# with a common Groovy/Gradle/Kotlin keyword or lambda variable name, and the scanned text is
# not an actual call to the deprecated API.
#
# Every entry must be preceded by a '#' comment giving the reason it is a false positive.
# An unexplained entry cannot be re-verified by anyone else later (enforced by AllowlistTest).

# whole grouped deprecation (every sibling class the report lists under 'Declared in: ...').
# Do not list '$DefaultImpls' classes - they are never indexed. Same for non-KGP packages:
# only 'org.jetbrains.kotlin.*' is indexed, so third-party symbols cannot be reported.
